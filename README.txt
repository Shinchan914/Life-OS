LIFE OS — Android starter

WHAT'S INCLUDED
- Daily checklist with five categories
- Daily completion percentage and progress bar
- Current streak and longest streak
- Monthly consistency calendar
- Local-only saving (browser localStorage)
- JSON export backup
- Offline cache after first successful load

RUN LOCALLY
For a quick computer preview, open index.html in a browser. Service-worker/offline installation features require HTTPS or localhost.

INSTALL ON ANDROID
1. Upload the complete contents of this folder to a static HTTPS host (for example, Netlify Drop or GitHub Pages).
2. Open the resulting HTTPS website in Chrome on Android.
3. Open Chrome's menu and choose “Install app” or “Add to Home screen” (wording varies).
4. Launch LIFE OS from the new home-screen icon.

DATA
Progress is stored in this browser on this device. Clearing browser site data can erase it. Use Settings > Export my data regularly to save a backup. Exported backups are not automatically imported by this starter version.

NOTE
This is a PWA, not a Play Store APK. It can be installed from Chrome after hosting over HTTPS.
